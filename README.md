# POTREROS Campo · versiones

Desde acá se descargan las versiones de **POTREROS Campo**, la edición que el
productor usa en su computadora o su celular, sin internet y sin cuenta.
Grupo de Ganadería Subtropical · INTA EEA Corrientes.

- Las versiones están en **Releases**: el instalador de Windows y el APK de Android.
- `ultima-version.json` le dice a la app cuál es la última versión. La app lo
  consulta sólo si el productor prende "Buscar versiones nuevas", y no manda
  ningún dato del campo.

Este repositorio no tiene el código de la app ni datos de productores.

**Para actualizar:** instalá la versión nueva encima de la que tenés, sin
desinstalar. Antes, guardá un respaldo desde la app.
